# Definition of Done

A feature is not done merely because it compiles.

At minimum, where applicable:

- implementation exists
- unit/integration tests exist
- security implications reviewed
- performance implications measured where relevant
- platform behavior checked on Windows and Linux when applicable
- user-visible error states exist
- documentation updated
- decision log updated if architecture changed
- metadata/provenance recorded for generated artifacts
- no secret data added to logs, fixtures or repository history

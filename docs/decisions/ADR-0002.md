# ADR-0002: Semantic Filename Grammar

**Status:** Accepted  
**Date:** 2026-08-16

## Decision

Default filename grammar is `<Semantic Title>_<DDMMMYYYY>.<extension>`. The default date is document creation date.

## Consequences

This decision is treated as a cross-project constraint. Any implementation that conflicts with it requires a new ADR explicitly superseding this one.

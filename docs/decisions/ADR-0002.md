# ADR-0002: Rust as the Implementation Language

**Status:** Accepted
**Date:** 2026-08-16

## Context

The product's performance targets (specs.md section 22) and its security
surface -- parsers over untrusted files, encrypted documents, memory-mapped
huge files -- both push toward a language with no garbage-collector pauses
and no uninitialised-memory class of bug.

## Decision

Rust is the primary implementation language. The product is built as a Cargo
workspace of `bp-*` crates plus a thin `apps/bachelorpad` binary.

## Consequences

- Library choices are constrained to the Rust ecosystem or to what can be
  wrapped safely.
- `unsafe` is not banned outright, but crates that do not need it declare
  `#![forbid(unsafe_code)]` so that the exceptions are visible.
- The UI toolkit decision (ADR-0015) is constrained to Rust-native or
  Rust-bindable toolkits.

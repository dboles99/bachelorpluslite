# ADR-0001: Target Platforms

**Status:** Accepted  
**Date:** 2026-08-16

## Decision

BachelorPad+ targets Windows 10, Windows 11 and Linux. Portable functionality belongs in shared Rust crates; OS-specific behavior must be isolated behind platform adapters.

## Consequences

This decision is treated as a cross-project constraint. Any implementation that conflicts with it requires a new ADR explicitly superseding this one.

# ADR-0001: Target Platforms

**Status:** Accepted
**Date:** 2026-08-16

## Context

BachelorPad+ is a desktop text appliance. The platforms it must serve
determine how much behaviour can live in portable Rust and how much needs an
adapter, and that shapes the crate layout from the first commit.

## Decision

Target Windows 10, Windows 11 and Linux. Portable functionality belongs in
shared Rust crates. OS-specific behaviour is isolated behind traits in
`bp-platform`, implemented by `bp-platform-windows` and `bp-platform-linux`.

## Consequences

- Windows-only services must not leak into the portable core.
- Anything that cannot be expressed portably needs an entry in
  `docs/architecture/PLATFORM_MATRIX.md` rather than a silent divergence.
- Verification has to cover both platforms; on this project that is the
  `-Linux` leg of the local CI gate (see ADR-0016).

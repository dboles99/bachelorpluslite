# ADR-0004: Default Editor Integration

**Status:** Accepted  
**Date:** 2026-08-16

## Decision

BachelorPad+ registers as a supported handler and uses OS-supported default-app mechanisms. It does not replace or patch `notepad.exe`.

## Consequences

This decision is treated as a cross-project constraint. Any implementation that conflicts with it requires a new ADR explicitly superseding this one.

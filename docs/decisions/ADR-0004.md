# ADR-0004: Creation Date is the Filename Date

**Status:** Accepted
**Date:** 2026-08-16

## Context

The date in a filename could track creation or last modification. Tracking
modification means the filename changes on nearly every save, which breaks
links, breaks the user's memory of where things are, and makes a note's name
a moving target.

## Decision

The date component is the document's creation date. It does not change when
the document is saved.

## Consequences

- `Document::created_at` is set once and has no setter.
- A user who wants a new date takes a deliberate action (a new revision or an
  explicit rename), which is a decision, not a side effect.
- Asserted directly by a test in `bp-core`.

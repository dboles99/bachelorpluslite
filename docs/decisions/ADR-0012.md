# ADR-0012: Default Editor Integration

**Status:** Accepted
**Date:** 2026-08-16

## Context

Users want BachelorPad+ to open their text files. Windows offers supported
mechanisms for this; it is also technically possible to hijack or replace
`notepad.exe`, which some tools do.

## Decision

Register as a supported handler for the file types the product understands
and guide the user through the OS's own default-app selection. Do not
replace, patch, shim or redirect `notepad.exe`. On Linux, register a
`.desktop` entry and MIME associations through standard mechanisms.

## Consequences

- The user always retains the OS-level ability to change their mind.
- Association presets (Notepad Replacement, Text + Notes, Developer, and so
  on) are a UI convenience over the supported mechanism, not a bypass of it.
- Nothing the installer does can leave a system unable to open a text file if
  BachelorPad+ is removed.

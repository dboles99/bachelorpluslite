# ADR-0003: Security Architecture

**Status:** Accepted  
**Date:** 2026-08-16

## Decision

Protected documents use established KDF/AEAD implementations; no custom cryptography. Security policy propagates to recovery, history, clipboard, indexing, embeddings and temporary persistence.

## Consequences

This decision is treated as a cross-project constraint. Any implementation that conflicts with it requires a new ADR explicitly superseding this one.

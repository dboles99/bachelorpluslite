# ADR-0010: Clipboard History and Format-aware Paste

**Status:** Accepted
**Date:** 2026-08-16

## Context

specs.md section 14 requires clipboard history in the editor context menu,
Windows native clipboard history where available, a BachelorPad+ clipboard
panel, pinned items, type detection and format-aware paste transformations.

## Decision

Provide both: surface the OS clipboard history where the platform offers one,
and provide a BachelorPad+ clipboard panel that works identically on both
platforms. Persistent clipboard history is opt-in.

## Consequences

- Clipboard contents are frequently sensitive, so persistence is governed by
  the owning document's security profile (ADR-0011), including timed clearing
  and a secure-clipboard mode.
- Opt-in rather than on-by-default: silently retaining everything a user ever
  copied is a liability, not a feature.

# ADR-0009: Four Built-in Themes, Data-driven

**Status:** Accepted
**Date:** 2026-08-16

## Context

specs.md section 16 requires Light, Dark, Organic and Green themes plus
Follow System, covering editor, menus, tabs, status bar, borders, accent,
syntax, notebook cells and semantic indicators -- and says themes should be
user-editable.

## Decision

Ship Light, Dark, Organic and Green as built-ins, defined as data rather than
as code, so that user themes use the same mechanism the built-ins do.

## Consequences

- The UI toolkit must support restyling every surface, including text input
  widgets, from a palette supplied at runtime. This is an evaluation
  criterion in the toolkit spike (ADR-0015).
- A toolkit whose native widgets cannot be fully restyled forces either a
  custom widget set or a compromise on this ADR.

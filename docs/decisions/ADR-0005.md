# ADR-0005: Brand Boundary

**Status:** Accepted  
**Date:** 2026-08-16

## Decision

The brand uses an original retro-futurist appliance genre. No existing entertainment property's names, characters, logos, fictional companies, props, typography, dialogue, or distinctive assets are copied.

## Consequences

This decision is treated as a cross-project constraint. Any implementation that conflicts with it requires a new ADR explicitly superseding this one.

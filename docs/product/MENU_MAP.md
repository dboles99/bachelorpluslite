New, New Window, Open, Open Folder, Open Recent, Save, Save As, Save Copy, Save All, Revert, Reload, Print, Close.

Undo, Redo, Cut, Copy, Paste, Paste Special, Clipboard History, Select All, multi-cursor, line operations.

Theme, font, zoom, line numbers, word wrap, panels, inspectors, raw/structured/split modes.

Date/time, Markdown constructs, citation, code block, table, notebook cell.

Format-aware operations, encoding, line endings, indentation.

Document inspector, security inspector, file analysis, conversions, benchmarks, settings.

BachelorPad+

Everything Lite does, and the things it cannot.

Lite gives you a fast editor that remembers what you wrote. BachelorPad+ adds the things you would want next: notes that are actually encrypted, notebooks you can run code in, tools for the messy data files you get sent, and privacy controls that cover everything rather than the essentials. None of it is a mock-up. All of it has been built and run before.

BachelorPad+ is in development, and it has no date yet. Waitlist members hear first, and get in early.

What you get that Lite does not give you

Every item here existed and worked in an earlier version of this program. They were taken out to make Lite small and fast, and they are going back into the full version.

Privacy

Notes only you can open

Real encryption on a note or a whole folder, with a passphrase you choose. Modern, audited ciphers rather than a password prompt over a plain file. Your crash-recovery files get the same protection, which is the gap most editors leave open.

Safety

It warns you before you leak a password

Paste an API key or a connection string into a note and it tells you where it is, so it does not end up in a screenshot or a shared file. It can black out the sensitive parts, and strip the hidden metadata documents carry around.

Power

Notebooks you can actually run

Write a note, drop in a snippet of Python or SQL, and run it right there, one cell at a time and only when you ask. Jupyter-compatible, so your existing notebooks open and yours open elsewhere.

Everyday

Tidy up messy data files in place

Format and check JSON, YAML, TOML and CSV, sort keys, and convert between them without leaving the editor or pasting anything into a website.

Everyday

Everything you copied, still there

A searchable clipboard history, and paste that understands what you are pasting into so a table stays a table.

Scale

Open the log file that crashes other editors

Multi-gigabyte files open instantly and read smoothly, because they are streamed from disk instead of loaded whole.

Writing

Citations and references that stay offline

Track sources, identifiers and a reference list inside your notes, with nothing sent to a service and no account required.

Privacy

Privacy controls over everything

Four levels covering temporary files, network access, indexing and key storage, not just the two Lite keeps. Set it once and every document follows it.

The price is not set yet, and Lite stays free either way. Nothing in Lite will be taken away, moved behind a payment, or turned into a trial. If you only ever use the free version, that is a perfectly good outcome.

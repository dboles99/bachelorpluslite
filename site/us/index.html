Notepad when you want it. More when you need it.

BachelorPad+ Lite is a free, open source Notepad replacement for Windows and Linux. It edits plain text the way Notepad does, plus one thing Notepad cannot: it knows which of your notes are about the same subject, so you can find last month's thinking without remembering the filename. It opens instantly, works offline forever, and it will never run anything or send anything anywhere.

What you get

Everything below works today, in the free version, on Windows and on Linux. There is no account, no sign-in, and no trial period.

Familiar

You already know how to use it

Tabs, find and replace, go to line, undo, zoom, UTF-8, LF or CRLF. If you can use Notepad you can use this, and big files stay quick because editing costs what you changed rather than what the file weighs.

Time saved

It names your files for you

One menu item turns "untitled_3.txt" into Quarterly_Review_10SEP2026.md, taking the title from what you actually wrote. A folder of these sorts itself by date and reads like a list of subjects. You approve every rename before it happens.

Peace of mind

Your work survives a crash

Unsaved changes are kept through a crash, a forced quit or a power cut, and offered back to you next time you open the program. You choose, per document, whether it does this at all.

Speed

It opens instantly and stays out of the way

One 21 MB download, no runtime to install, no splash screen, no first-run wizard. Unpack it and it runs. Its settings, recent files and recovery journal live in your user profile, so removing it is deleting the folder and the three directories the manual lists, after undoing any file types you made it the default editor for.

Trust

Nothing you type ever leaves your computer

No telemetry, no update checks, no crash reports, no AI, no account. It behaves identically with the network cable pulled out, and because the source is public you can check that rather than take our word for it.

Trust

It cannot run anything, ever

There are no scripts, macros or plugins, so a document you were sent cannot do anything when you open it. It also will not grab your file associations or delete anything from your machine without showing you first.

The part that is not Notepad: it remembers

Open a note and the program quietly learns what it is about. Nothing leaves your machine, your notes stay as ordinary files you can open in anything else, and one setting turns the whole thing off.

Find things

"What else did I write about this?"

One click lists every note that covers the same ground as the one you are reading, closest first. This is the feature people keep it for: your own thinking from three months ago, found without remembering where you put it.

Stay tidy

It spots when you have written this before

Save something close to a note you already have, and it tells you, so you end up with one good note instead of four half ones.

Step back

See the shape of everything you have written

A single report over your whole collection: what you keep coming back to, which notes are stranded and connected to nothing, and what is worth merging. It also tells you what it did not look at, so you know how much to trust it.

All of it is optional and it is off in one setting. The Privacy menu decides whether anything is written down about a document at all. Turn it off and the features say so plainly instead of quietly doing nothing.

Exactly what gets written down, and where

Two things, and nothing else: a recovery file so a crash does not cost you work, and an index entry so the note features work. Both are real trades, so here they are rather than a paragraph of reassurance.

SettingCrash recovery fileKept about the document
Standardyes, not encryptedPath, title and topics
Privateyes, not encryptedThe path only
ConfidentialnoneNothing
MaximumnoneNothing

The menu shows you both of these at all times, so you never have to guess which one you are on. Nothing here is encrypted, and the program says so rather than implying otherwise. Privacy Mode tightens everything for the session and clears recovery files already written.

Download it free

Version 0.9.5, for Windows 10, Windows 11 and Linux. No installer and no account: unpack the archive wherever you like and run it. Settings, recent files and the recovery journal are written to your user profile rather than beside the program, and the manual lists exactly where.

Windows 10 / 11 bachelorpad-lite-0.9.5-windows-x86_64.zip Linux bachelorpad-lite-0.9.5-linux-x86_64.tar.gz All releases Checksums and notes
Windows will warn you the first time, and here is why. Code-signing certificates cost money this project does not have yet, so SmartScreen shows a warning. Click "More info", then "Run anyway". Self-signing was rejected because it would ask you to install a root certificate you have no reason to trust, which is worse than a warning.

If you want to confirm the download is the one published, every release ships a checksum file.

sha256sum -c SHA256SUMS.txt

Windows and Linux, 64-bit. There is no macOS build. macOS would need different file locations, a different way of registering file types, and an Apple certificate before it would open at all. It is not ruled out, but it is not built.

This list is only for free-version releases. The BachelorPad+ waitlist is separate, and joining one does not join the other. If you would rather not give an address at all, you can watch releases on GitHub. Privacy.

Open source, and what it is built on

Every line is public and licensed under GPL-3.0-only. You can read it, build it, change it, and ship your changes. Nothing is held back in a paid edition of Lite, and there is no contributor agreement that signs your work away.

Open source

Why that matters to you and not just to us

This program claims it never touches the network and cannot run anything. Open source is what turns that from a promise into something you can check, by yourself or by anyone you trust. It also means the program cannot be taken away from you: if this project stops, your copy keeps working and somebody else can pick it up.

How to help

How to help

Bug reports are the most useful thing, and the issue templates ask for the few details that make a report fixable. Translations, documentation fixes and code are all welcome. If you just want the thing to succeed, telling one person who still uses Notepad does more than you would think.

Standing on other people's work

BachelorPad+ Lite is built in Rust and would not exist without these projects. The full list of every library in the binary, with its license, ships inside the download and is in the repository.

  • Rust
  • Slint, the user interface toolkit, used under its GPL-3.0 license
  • ropey, the rope that keeps editing fast in large files
  • SQLite / rusqlite, SQLite, via rusqlite, holding the note index on your machine
  • rfd, native open and save dialogs on both platforms
  • arboard, clipboard access
  • regex, find and replace
  • serde, reading and writing your settings
  • tracing, diagnostics, when you ask for them

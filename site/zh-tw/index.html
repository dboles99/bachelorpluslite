BachelorPad+ Lite 是 Windows 與 Linux 上免費且開放原始碼的記事本替代工具。它像記事本一樣編輯純文字，還多了一件記事本做不到的事：它知道你哪幾則筆記在談同一件事，所以你不必記得檔名也能找回上個月的想法。開啟只要一瞬間，可以永遠離線使用，而且它永遠不會執行任何東西，也不會把任何東西送到別處。

你會得到什麼

下面每一項今天就能用，在免費版裡，Windows 與 Linux 都可以。不需要帳號，不必登入，也沒有試用期。

熟悉

你已經知道怎麼用了

分頁、尋找與取代、跳到指定行、復原、縮放、UTF-8、LF 或 CRLF。會用記事本就會用它。大檔案也不會變慢，因為編輯的成本取決於你改了多少，而不是檔案有多大。

省時間

它會幫你把檔案取好名字

一個選單指令就能把「未命名 3.txt」變成 Quarterly_Review_10SEP2026.md，標題直接取自你寫的內容。這樣的資料夾會自動依日期排序，看起來就像一張主題清單。每次改名都要你同意才會執行。

安心

你的工作能撐過當機

尚未儲存的變更會在當機、強制關閉或停電後保留下來，下次開啟程式時再交還給你。要不要這麼做，由你逐份文件決定。

速度

開啟很快，也不礙事

一個小小的下載，不需安裝執行環境，沒有啟動畫面，也沒有首次執行精靈。安裝時不會要求系統管理員權限，也可以解壓縮後直接執行。設定、最近開啟的檔案與復原日誌都放在您的使用者設定檔中，所以移除它就是解除安裝或刪除資料夾，再刪除手冊列出的三個目錄。

信任

你打的字永遠不會離開你的電腦

沒有遙測、沒有更新檢查、沒有當機回報、沒有 AI、不需要帳號。拔掉網路線它的行為完全一樣，而且原始碼公開，你可以自己確認，不必只聽我們說。

信任

它永遠不會執行任何東西

沒有指令碼、巨集或外掛，所以別人寄給你的文件在開啟時不會做任何事。它也不會搶走你的檔案關聯，或在沒有先讓你看過的情況下刪掉你電腦上的東西。

記事本沒有的那一部分：它記得

打開一則筆記，程式會安靜地認識它在談什麼。沒有任何東西離開你的電腦，你的筆記仍然是可以用其他軟體開啟的一般檔案，而且一個設定就能整個關掉。

找得到

「這件事我還寫過什麼？」

點一下就會列出和你正在讀的這則談同樣事情的所有筆記，最接近的排最前面。這是大家留下來用它的原因：三個月前自己的想法，不必記得放在哪裡也找得回來。

保持整齊

它會發現你已經寫過一次了

當你儲存的內容和既有筆記很接近時，它會告訴你，於是你最後留下的是一則完整的筆記，而不是四則半成品。

退後一步

看見你寫過的全部長什麼樣子

一份涵蓋整批筆記的報告：你反覆回到哪些主題、哪些筆記孤立而沒有連到任何東西、哪些值得合併。它也會告訴你它沒有看過哪些部分，好讓你知道該信到什麼程度。

這一切都是選用的，一個設定就能關掉。隱私選單決定是否要對一份文件記下任何東西。關掉之後，這些功能會明白說出來，而不是悄悄地什麼都不做。

到底寫下了什麼，寫在哪裡

只有兩樣，沒有別的：一個復原檔，讓當機不會害你損失工作；還有一筆索引，讓筆記功能能運作。兩者都是實際的取捨，所以這裡直接列表，而不是寫一段安撫的話。

設定當機復原檔對這份文件記下的內容
標準有，未加密路徑、標題與主題
私密有，未加密只有路徑
機密沒有什麼都沒有
最高沒有什麼都沒有

選單隨時把這兩欄顯示給你看，所以你永遠不必猜自己在哪一個設定上。這裡沒有任何東西是加密的，程式直接這樣說，而不是暗示相反的事。隱私模式會為這次工作階段把所有設定收緊，並清除已經寫下的復原檔。

版本 1.0.0，適用於 Windows 10、Windows 11 與 Linux：Windows 有不需要系統管理員權限的安裝程式，Linux 有 .deb、.rpm 與 AppImage，另附一般壓縮檔。不需要帳號。設定、最近開啟的檔案與復原日誌會寫入您的使用者設定檔，而不是程式旁邊，手冊列出了確切位置。

Windows 10 / 11 bachelorpad-lite-1.0.0-windows-x86_64-setup.exe Linux .deb · .rpm · AppImage 所有版本 校驗碼與說明
第一次執行時 Windows 會警告你，原因在此。程式碼簽章憑證要花錢，這個專案目前沒有，所以 SmartScreen 會出現警告。點「其他資訊」，再點「仍要執行」。自我簽章被明確排除，因為那等於要你安裝一個你沒有理由信任的根憑證，那比一個警告更糟。

如果你想確認下載到的就是發佈的那一份，每個版本都附有校驗碼檔案。

sha256sum -c SHA256SUMS.txt

Windows 與 Linux，64 位元。沒有 macOS 版本。macOS 需要不同的檔案位置、不同的檔案類型註冊方式，而且要有 Apple 憑證才打得開。這件事沒有被排除，但目前沒有做。

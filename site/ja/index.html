BachelorPad+ Lite は Windows と Linux 向けの無料でオープンソースのメモ帳代替エディタです。メモ帳と同じようにプレーンテキストを編集でき、そのうえメモ帳にできないことが一つあります。あなたのどのノートが同じ話題を扱っているかを知っているので、ファイル名を覚えていなくても先月の考えを取り出せます。起動は一瞬、ずっとオフラインで使え、何かを実行することも、どこかへ送ることも決してありません。

できること

以下はすべて、無料版で、今日から使えます。Windows でも Linux でも同じです。アカウントもサインインも試用期間もありません。

慣れた操作

使い方はもう知っています

タブ、検索と置換、行へ移動、元に戻す、拡大縮小、UTF-8、LF または CRLF。メモ帳が使えるなら、これも使えます。大きなファイルでも軽いままです。編集の負担は変更した量で決まり、ファイルの大きさでは決まりません。

時間の節約

ファイル名を代わりに付けます

メニュー一つで「無題 3.txt」が Quarterly_Review_10SEP2026.md になります。題名は実際に書いた内容から取ります。こうしたファイルが並ぶフォルダは日付順に並び、主題の一覧のように読めます。改名はすべて、実行前にあなたが承認します。

安心

作業はクラッシュを生き延びます

未保存の変更はクラッシュ、強制終了、停電をまたいで保持され、次に開いたときに返されます。そもそも行うかどうかは、文書ごとにあなたが選びます。

速さ

すぐ開き、邪魔をしません

小さなダウンロードひとつ。ランタイムのインストールも、スプラッシュ画面も、初回起動ウィザードもありません。管理者権限の確認なしにインストールでき、展開するだけでも動きます。設定、最近使ったファイル、復元用ジャーナルはユーザー プロファイルに置かれるので、削除はアンインストールするかフォルダーを消し、マニュアルにある 3 つのディレクトリを消すだけです。

信頼

入力した内容がこの端末を出ることはありません

テレメトリなし、更新確認なし、クラッシュ報告なし、AI なし、アカウントなし。ネットワークを抜いても挙動は同じで、ソースが公開されているので、こちらの言葉を信じる代わりに自分で確かめられます。

信頼

何かを実行することは決してありません

スクリプトもマクロもプラグインもないので、送られてきた文書を開いても何も起こりません。ファイルの関連付けを勝手に奪うことも、先に見せずに何かを削除することもありません。

メモ帳にはない部分、つまり「覚えていること」

ノートを開くと、それが何についてのものかを静かに学びます。何もこの端末を出ず、ノートは他のソフトでも開ける普通のファイルのままで、設定一つで全体を止められます。

見つける

「これについて他に何を書いたか」

一度クリックすれば、いま読んでいるものと同じ範囲を扱うノートがすべて、近い順に並びます。使い続ける理由はたいていこれです。三か月前の自分の考えを、どこに置いたか覚えていなくても取り出せます。

散らからない

同じことを前にも書いたと気づきます

すでにあるノートに近いものを保存すると教えてくれるので、中途半端なノートが四つではなく、良いノートが一つ残ります。

俯瞰する

書いてきたもの全体の形が見えます

収集物全体についての一つの報告書です。何度も戻ってくる主題、どこにもつながっていないノート、まとめる価値のあるもの。見ていない範囲も伝えるので、どこまで信じてよいかが分かります。

すべて任意で、設定一つで止められます。プライバシー メニューが、文書について何かを書き留めるかどうかを決めます。止めると、機能は黙って何もしないのではなく、そう明言します。

何がどこに書かれるのか

書かれるのは二つだけです。クラッシュで作業を失わないための復旧ファイルと、ノート機能を動かすための索引の項目です。どちらも実際の取引なので、安心させる文章ではなく表を置きます。

設定クラッシュ復旧ファイル文書について保持する内容
標準あり、暗号化なしパス、題名、話題
プライベートあり、暗号化なしパスのみ
機密なしなし
最大なしなし

メニューは常にこの二つを表示するので、いまどちらなのかを推測する必要はありません。ここに暗号化されたものはなく、そのことを別の言い方でごまかしません。プライバシー モードはこの作業のあいだ全体を締め、すでに書かれた復旧ファイルを消します。

無料でダウンロード

バージョン 1.0.0、Windows 10、Windows 11、Linux 向け。Windows には管理者権限の要らないインストーラ、Linux には .deb、.rpm、AppImage を用意し、そのほかに通常のアーカイブもあります。アカウントは不要です。設定、最近使ったファイル、復元用ジャーナルはプログラムの横ではなくユーザー プロファイルに書き込まれ、その場所はマニュアルに正確に記載されています。

Windows 10 / 11 bachelorpad-lite-1.0.0-windows-x86_64-setup.exe Linux .deb · .rpm · AppImage すべてのリリース チェックサムと注記
初回だけ Windows が警告します。その理由をお伝えします。コード署名証明書には費用がかかり、この計画にはまだその余裕がないため、SmartScreen が警告を出します。「詳細情報」を押し、「実行」を選んでください。自己署名は選びませんでした。信頼する理由のないルート証明書を導入してもらうことになり、警告よりも悪いからです。

ダウンロードしたものが公開されたものと同じか確認したい場合、各リリースにチェックサム ファイルが付いています。

sha256sum -c SHA256SUMS.txt

Windows と Linux、64 ビット。macOS 版はありません。macOS ではファイルの置き場所も、ファイル種別の登録方法も異なり、そもそも開くために Apple の証明書が要ります。可能性を否定してはいませんが、作ってはいません。

新しい版が出たら知らせる

Lite の新しい版が出たときに、何が変わったかを書いた短いメールを一通。それ以外は送らず、いつでも抜けられます。

このリストは無料版のリリース告知にだけ使います。BachelorPad+ の順番待ちリストは別で、片方に入ってももう片方には入りません。アドレスをまったく渡したくない場合は、 GitHub でリリースを購読する. プライバシー.

オープンソースであること、そしてその土台

すべての行が公開されており、GPL-3.0-only の下にあります。読み、ビルドし、変更し、その変更を配布できます。Lite の有料版に何かを隠しておくことはなく、あなたの仕事を手放させる貢献者契約もありません。

オープンソース

それがあなたにとって意味を持つ理由

この製品は、ネットワークに触れず何も実行できないと述べています。ソースが公開されていれば、その約束はあなた自身、または信頼できる誰かが確かめられるものになります。取り上げられない、という意味でもあります。この開発が止まっても、あなたの手元の版は動き続け、誰かが引き継げます。

手伝っていただけること

手伝っていただけること

不具合の報告がいちばん助かります。報告用のひな形は、直せる報告にするために必要な少数の項目だけを尋ねます。翻訳、ドキュメントの修正、コードも歓迎です。ただ成功してほしいだけなら、まだメモ帳を使っている人に一人伝えるだけでも、思う以上の効果があります。

他の人の仕事の上に立っています

BachelorPad+ Lite は Rust で書かれており、以下のプロジェクトなしには存在しません。実行ファイルに含まれるすべてのライブラリとそのライセンスの一覧は、ダウンロードに同梱され、リポジトリにもあります。

  • Rust
  • Slint, 画面を描く道具一式。GPL-3.0 ライセンスで利用しています
  • ropey, 大きなファイルでも編集を速く保つ rope 構造
  • SQLite / rusqlite, SQLite（rusqlite 経由）。ノートの索引をあなたの機械に保持します
  • rfd, 両プラットフォームでのネイティブな開く・保存ダイアログ
  • arboard, クリップボードへのアクセス
  • regex, 検索と置換
  • serde, 設定の読み書き
  • tracing, 求めたときの診断情報

完全版は開発中です

Lite は無料の半分で、これからも無料です。BachelorPad+ は完全版です。暗号化されたノート、実行できるノートブック、構造化データの道具、クリップボード履歴、そしてすべてのプライバシー設定。現在開発中で、公開日はまだ決まっていません。順番待ちリストの方が最初に知らせを受け、早く使えます。

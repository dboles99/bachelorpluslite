BachelorPad+

Lite にできることすべてと、できないこと。

Lite は、書いた内容を覚えている速いエディタです。BachelorPad+ は、その次に欲しくなるものを足します。本当に暗号化されるノート、コードを実行できるノートブック、送りつけられる雑なデータ ファイルのための道具、そして最低限ではなくすべてを覆うプライバシー設定。どれも試作ではありません。すべて過去に作られ、実際に動いていたものです。

プライバシー

あなたにしか開けないノート

一つのノートにも、フォルダ全体にも、本物の暗号化を。合言葉はあなたが決めます。平文ファイルにパスワード入力を被せるのではなく、現代的で検証済みの方式を使います。クラッシュ復旧ファイルも同じ保護を受けます。多くのエディタが開けたままにしている穴は、まさにそこです。

安全

パスワードを漏らす前に知らせます

API キーや接続文字列をノートに貼ると、どこにあるかを教えます。スクリーンショットや共有ファイルに紛れ込まずに済みます。該当箇所を塗りつぶすことも、文書が抱えている隠れたメタデータを取り除くこともできます。

能力

本当に実行できるノートブック

ノートを書き、Python や SQL の断片を置いて、その場で実行します。一度に一つのセルだけ、しかも求めたときだけ動きます。Jupyter 互換なので、手持ちのノートブックが開き、こちらで作ったものも他所で開けます。

日常

散らかったデータ ファイルをその場で整える

JSON、YAML、TOML、CSV の整形と検査、キーの並べ替え、相互変換。エディタを離れる必要も、どこかのウェブサイトに貼り付ける必要もありません。

日常

コピーしたものが残っています

検索できるクリップボード履歴と、貼り付け先を理解する貼り付け。表は表のままです。

規模

他のエディタが落ちるログ ファイルを開く

数ギガバイトのファイルが即座に開き、滑らかに読めます。丸ごと読み込むのではなく、ディスクから流し込むからです。

執筆

オフラインのままの引用と参考文献

出典、識別子、参考文献の一覧をノートの中で管理します。どこかのサービスへ送られることはなく、アカウントも要りません。

プライバシー

すべてを覆うプライバシー設定

Lite が残した二つではなく、一時ファイル、ネットワーク接続、索引作成、鍵の保管まで含む四段階。一度決めれば、すべての文書がそれに従います。

価格はまだ決めていません。そして、どちらにせよ Lite は無料のままです。Lite にあるものが取り上げられたり、支払いの向こう側に移されたり、試用に変えられたりすることはありません。ずっと無料版だけを使うとしても、それはまったく良い結果です。

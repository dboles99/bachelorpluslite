## Thresholds

  build 50 rows   < 1.6 ms   (a tenth of a 16 ms frame)
  size independence  < 4x     (largest document vs smallest, same run)

  all within threshold.

**Not measured here:** rasterisation and end-to-end input latency, which are the other half of ADR-0017's revert condition and need a capture rig.

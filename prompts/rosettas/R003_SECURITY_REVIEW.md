# Rosetta R003: Security Review

Review a BachelorPad+ feature against:
- security profiles
- recovery/history propagation
- clipboard persistence
- semantic metadata/embeddings
- logs
- temp files
- cloud/network eligibility
- malformed/untrusted input

Do not propose custom cryptography.
For cryptographic primitives, require current primary documentation/review before implementation.
Produce:
- threat summary
- data-flow notes
- findings by severity
- recommended fixes
- tests
- unresolved assumptions
